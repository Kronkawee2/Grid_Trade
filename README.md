# Quant Grid ML — Adaptive Grid Research

EURUSD และ XAUUSD จาก Dukascopy (ข้อมูลสร้างจาก tick ย้อนหลัง 20-23 ปี) มาทดสอบสมมติฐานที่ว่าระบบกริดซึ่งปรับขนาดตามความผันผวนและมีการควบคุมความเสี่ยงที่รัดกุม สามารถสร้างผลตอบแทนที่เป็นบวกอย่างต่อเนื่องบนทุนขนาดเล็ก ($100) ได้จริงหรือไม่ วิธีทดสอบคือสร้าง baseline ที่ตรวจสอบได้ก่อน แล้วเปิดฟีเจอร์ทีละอย่างเพื่อดูว่าอะไรคือสิ่งที่ทำให้ระบบรอด ไม่เชื่อผลรวมที่ดูดี แต่ทุกการเปลี่ยนแปลงต้องทำให้ทั้งสองตลาดดีขึ้นพร้อมกันโดยไม่จูนค่าแยกรายตลาด

ชื่อโปรเจกต์มีคำว่า ML แต่ยังไม่มี ML อยู่ในนั้น เพราะโมเดลจะวัดผลได้ก็ต่อเมื่อมี baseline ให้เทียบ และการสร้าง baseline ที่เชื่อถือได้กลายเป็นงานเกือบทั้งหมดของโปรเจกต์นี้

## ผลการทดลอง

ทดสอบระบบกริด 5 เวอร์ชัน (ตั้งแต่กริดเปล่าจนถึงเวอร์ชันที่มีการควบคุมครบ) กับ 2 สินทรัพย์ที่ไม่เกี่ยวข้องกัน บนข้อมูล 19 ปีชุดเดียวกัน โดยใช้ค่าพารามิเตอร์ชุดเดียวทั้งสองตลาด ไม่มีการจูนแยก

ผลสรุป: **ระบบทำกำไรได้จริงทั้งสองตลาด แต่ยังไม่ผ่านเกณฑ์ที่จะเรียกว่ามี edge ที่พิสูจน์แล้ว** เพราะ (1) ยังไม่เคยผ่าน walk-forward บนเครื่องยนต์เวอร์ชันปัจจุบัน (2) **91% ของวันทั้งหมด บัญชีไม่ทำจุดสูงสุดใหม่** โดย EURUSD เคยติดอยู่ที่ยอดเดิมนาน 7 ปี 4 เดือน และ (3) ยังไม่เคยรันจริงแม้แต่บนบัญชีเดโม

สิ่งที่พิสูจน์ได้ชัดเจนคือ **มูลค่าทั้งหมดของระบบอยู่ที่การควบคุมความเสี่ยงและการเลือกเวลา ไม่ได้อยู่ที่ตัวกริด** — กริดเปล่าๆ พอร์ตแตกทุกกรณี และตัวที่พลิกจาก "แตก" เป็น "กำไร" คือเพดานตัดวงจร ไม่ใช่กลไกการวางออเดอร์

## ทำไมระบบกริดถึงล้างพอร์ต

กริดคือการวางออเดอร์ limit เป็นชั้นๆ รอบราคาปัจจุบัน แล้วเก็บกำไรทีละน้อยเมื่อราคาแกว่งไปมา ปัญหาคือมันสวนทางตลาดโดยธรรมชาติ

* **เมื่อตลาดแกว่งในกรอบ:** ราคาวิ่งขึ้นลงผ่านชั้นต่างๆ เก็บกำไรได้เรื่อยๆ ดูเหมือนเครื่องพิมพ์เงิน
* **เมื่อตลาดวิ่งทางเดียว:** ทุกชั้นถูกเปิดหมดและขาดทุนพร้อมกัน ยิ่งราคาไปไกลยิ่งขาดทุนมาก ไม่มีจุดจบในตัวมันเอง

ระบบกริดส่วนใหญ่จึงมี equity curve ที่สวยงามเป็นเดือนหรือเป็นปี **แล้วจบในวันเดียว** และไม่มีสัญญาณเตือนล่วงหน้า โปรเจกต์นี้จึงตั้งโจทย์ที่การควบคุมความเสียหายก่อน ไม่ใช่ที่การหากำไร

## หลักการทำงานทั้งหมด: 5 ชั้น

ทุกชั้นถูกเพิ่มเข้ามาตามลำดับ และแต่ละชั้นถูกวัดผลแยกว่าให้อะไรบ้าง (ไม่มี Machine Learning เป็นกฎเชิงกลไกล้วน)

### ชั้น 1 — กริดที่ปรับตามความผันผวน

ระยะห่างระหว่างชั้นไม่ใช่ค่าคงที่ แต่เป็น `4.2 × ATR(20)` คำนวณใหม่ทุกครั้งที่ปักหมุด แล้วล็อกไว้ตลอดรอบนั้น

ทำให้ค่าชุดเดียวมีความหมายเท่ากันทั้งบน EURUSD ที่ขยับวันละ 60 pip และทองคำที่ขยับวันละ 700 pip — วัดจริงแล้วระยะห่างวิ่งตั้งแต่ **5.0 ถึง 189.0 pip** ตามสภาพตลาด (ต่างกัน 38 เท่า) จากพารามิเตอร์ตัวเดียวที่ไม่เคยเปลี่ยน

### ชั้น 2 — เพดานจำนวนไม้

เปิดพร้อมกันได้ **ไม่เกิน 3 ไม้** ไม่ว่าราคาจะแตะกี่ชั้น ทำให้ความเสียหายสูงสุดต่อรอบคำนวณได้ล่วงหน้า (`3 ไม้ × 4.5 ช่อง × ระยะห่าง`) โดยไม่ต้องพึ่งสถิติจากอดีต

### ชั้น 3 — รอราคาเด้งก่อนเข้า (Momentum Confirmation)

ราคาแตะเส้นแล้ว**ยังไม่เข้าไม้ทันที** ต้องรอให้ราคาเด้งกลับมา `0.45` ช่องก่อน จึงเข้าที่ราคานั้น เป็นการหลีกเลี่ยงการ "รับมีด" ในขณะที่ราคายังไหลลงต่อ

ราคาที่ต้องจ่ายคือได้ราคาเข้าที่แย่กว่าเดิม และชั้นที่ราคาไม่เด้งเลยจะไม่ถูกเทรด

### ชั้น 4 — เพดานตัดวงจร (Equity Stop)

**ชั้นที่สำคัญที่สุด** ทำงานที่ระดับบัญชี ไม่ใช่ระดับออเดอร์

> ถ้ายอดเงินรวม (นับกำไรลอยด้วย) ต่ำกว่าจุดสูงสุดที่เคยทำได้ **$22** → **ปิดทุกไม้ทันที** แล้วห้ามเปิดใหม่ 350 แท่ง

ต่างจาก stop ของกริดตรงที่ stop ของกริดคุมได้แค่รอบเดียว — ถ้าตลาดเป็นเทรนด์ยาว กริดจะปักหมุดใหม่แล้วโดนอีก วนไปเรื่อยๆ ส่วนเพดานตัดวงจรคุม **ความเสียหายสะสมข้ามหลายรอบ** และบังคับให้หยุดพัก

เพดานนี้ต้องขยายตามขนาดไม้เมื่อทบต้น — ถ้าปล่อยค้างไว้ที่ $22 ขณะที่ lot โตขึ้น 30 เท่า มันจะหดเหลือ **0.073 pip** ซึ่งเล็กกว่าสเปรด และหมดความหมาย

### ชั้น 5 — ตัวกรองสภาวะและเวลา

* **ตัวกรองความผันผวน:** ห้ามเปิดไม้ใหม่ขณะ `ATR(20) / ATR(200) > 1.15`
* **ตัวกรองเวลา:** ห้ามเปิดไม้ในช่วงที่พิสูจน์แล้วว่าขาดทุน (ยังอยู่ระหว่างตัดสินใจว่าจะใช้หรือไม่)

> **ข้อค้นพบสำคัญเกี่ยวกับตัวกรองความผันผวน**
> วัดแล้วพบว่า **66.5% ของค่าตัวกรองนี้อธิบายได้ด้วย "ตอนนี้กี่โมง" เพียงอย่างเดียว** เพราะ ATR(200) บน m5 กินเวลาแค่ 17 ชั่วโมง ซึ่งสั้นกว่าหนึ่งวัน จึงแยกไม่ออกระหว่าง "ตลาดผันผวนผิดปกติ" กับ "ตอนนี้ 11 โมง" ผลคือมันบล็อกช่วงลอนดอน/นิวยอร์ก 76-97% ซึ่งเป็นช่วงที่ทำกำไร แต่ปล่อยช่วงเอเชียผ่าน 97-99% ซึ่งเป็นช่วงที่ขาดทุน
> การขยายหน้าต่างเป็น 1 วัน 5 วัน หรือ 1 เดือน **แก้ไม่ได้** (ลดจาก 66% เหลือแค่ 45% แล้วตัน) เพราะปัญหาอยู่ที่ตัวตั้ง ไม่ใช่ตัวหาร

### การทดลองที่ 1 — แต่ละชั้นให้อะไรบ้าง (Ablation)

เปิดฟีเจอร์ทีละอย่างตามลำดับที่ถูกเพิ่มเข้ามา ข้อมูล 2006-2024, m5, 0.01 lot, เริ่มที่ $100

| เวอร์ชัน | EURUSD จบที่ | maxDD | XAUUSD จบที่ | maxDD |
| :--- | ---: | ---: | ---: | ---: |
| 1. กริด ATR เปล่าๆ | **แตก** | 406% | **แตก** | 3,458% |
| 2. + ตัวกรองความผันผวน | **แตก** | 2,291% | **แตก** | 4,606% |
| 3. + รอราคาเด้งก่อนเข้า | **แตก** | 440% | **แตก** | 588% |

EURUSD ติดอยู่ที่ยอด $440 ตั้งแต่ มิ.ย. 2015 ถึง ต.ค. 2022 — **เจ็ดปีสี่เดือน** ในความเป็นจริงไม่มีใครถือผ่านช่วงนั้นได้

**และความผันผวนไม่ใช่คำอธิบาย** — ตอนนิ่ง EURUSD ผันผวน 7.8% ตอนโต 8.6% ส่วนทองคำตอนนิ่ง 16.9% ตอนโต 16.6% คือแทบไม่ต่าง **ยังไม่ทราบสาเหตุ**

## ข้อผิดพลาดที่พบระหว่างทางและแก้แล้ว

บันทึกไว้เพราะผลลัพธ์ทั้งหมดก่อนการแก้เหล่านี้ใช้ไม่ได้ และเก็บไว้ใน `_invalid_outputs/`

1. **วัด drawdown ผิด** — หารด้วยเงินตั้งต้น $100 แทนที่จะหารด้วยยอดสูงสุดที่ร่วงลงมา ทำให้รายงานว่าทองคำ m15 "พอร์ตแตก 114%" ทั้งที่จริงคือ 22% และจบที่ $440
2. **ปิดไม้ในแท่งเดียวกับที่เปิด** — เพดานตัดวงจรปิดไม้ได้ในแท่งเดียวกับที่เปิดถึง 86-92% ของครั้ง และได้กำไรขั้นต้นเป็นบวก คือการขาดทุนที่ทำเงินได้ ซึ่งเป็นลายเซ็นของการมองอนาคต
3. **คำนวณ true range ข้ามช่องว่างข้อมูล** — ทองคำมี 466 วันที่ดึงไม่สำเร็จ ทำให้ค่าที่จุดต่อพุ่ง 10-100 เท่า แล้วไหลเข้าค่าเฉลี่ย 200 แท่งไปกำหนดขนาดกริดผิด
4. **Dukascopy ส่งไฟล์ปลอม** — วันที่ยังไม่มีข้อมูลจริงถูกตอบกลับด้วยไฟล์สมบูรณ์ที่ทุกแท่งราคาเท่ากันและ volume เป็นศูนย์ (ทองคำปี 2003 ราคา 1.25 ทั้งเดือน) แก้โดยเพิ่มตัวตรวจใน `quantdata`
5. **ทองคำถูกตัดสินจากข้อมูล 1.4 ปี** เทียบกับ EURUSD 20 ปี แก้โดยดึง Dukascopy ย้อนหลัง 23 ปี

## ML ควรทำอะไร

ไม่ใช่ทำนายราคา มี 3 ทางเลือก เรียงตามความพร้อมของข้อมูล

1. **ไม้นี้ควรเปิดไหม** — ทุกไม้ในอดีตมีคำตอบจริงอยู่แล้ว เป็น classification ธรรมดา แต่มีแค่ราว 2,500 ไม้ต่อตลาดใน 20 ปี ข้อมูลน้อยและ overfit ง่าย
2. **ช่วงข้างหน้าควรเทรดไหม** — ตรงกับปัญหาช่วงนิ่งที่สุด แต่มีข้อมูลแค่ ~230 เดือน และการทำนายถูกว่าจะเงียบให้ผลลัพธ์แค่ "อย่าเทรด" ไม่ได้ทำให้มีกำไร
3. **ระยะห่างกริดควรเป็นเท่าไหร่** — แทนตัวคูณ 4.2 ที่ตายตัวด้วยค่าที่โมเดลเลือก

**โมเดลต้องชนะตัวเลขข้างบนใน out-of-sample** ความแม่นของ classification เพียงอย่างเดียวไม่พิสูจน์อะไร

## ที่ยังไม่ได้ทำ

- **ยังไม่เคยรันจริงหรือ forward test** ทุกตัวเลขเป็น backtest ล้วน
- **ยังไม่เคย walk-forward บนเครื่องยนต์เวอร์ชันปัจจุบัน** — ที่เคยทำเป็นกริดเส้นตรงแบบเก่า ค่าที่ใช้อยู่จึงยังพิสูจน์ไม่ได้ว่าไม่ใช่ overfit
- ยังไม่ได้ตัดสินใจเรื่องตัวกรองเวลา (ผลการทดลองที่ 4)
- ยังไม่ทราบสาเหตุของช่วงนิ่ง 91%
- ยังไม่ได้ตรวจว่าไม้ที่เปิดตอนเอเชียขาดทุนตอนเอเชียเอง หรือตอนถือข้ามไปเจอตลาดยุโรป
- ยังไม่ได้ดึงข้อมูล Nasdaq ย้อนหลัง (ตั้งค่าไว้พร้อมแล้วที่ `NDX100.DUKA`)
- ยังไม่ได้จำลอง slippage ตอนโดน stop — ที่ 2 pip กินกำไรราว 10% ที่ 10 pip หายครึ่ง
- ทองคำไม่มีข้อมูลสเปรดย้อนหลัง ต้นทุนใช้สเปรดคงที่ของโบรกแทน
- ทองคำยังขาดข้อมูล 50 วันจากทั้งหมด ~6,000 วัน (0.8%)
